Build notes

Short notes, not tutorials.

先把正在反复验证的观点写下来。以后这里可以继续拆成独立文章页，而首页保持轻量。

2026.09PixiJS or Phaser? Start with the interaction model.+
如果核心是精细的渲染编排、资源组合和自定义状态机，我通常更喜欢更薄的渲染层；如果关卡、输入、场景与游戏循环本身就是主要复杂度，完整游戏框架会更省心。先看“复杂度在哪里”，再选引擎，比先站队框架更有效。
2026.09Model routing beats “one model for everything”.+
我的偏好是把默认模型留给大多数编码与推理，把高成本能力留给真正困难的任务；媒体生成、检索和容灾再交给专门服务。工作流的价值来自稳定切换，而不是永远追最新排行榜第一名。
2026.09Determinism is a product feature for small interactive builds.+
当一个互动作品需要反复验收、截图对比或自动测试时，可重复结果会显著降低沟通成本。随机性可以存在，但最好被 seed、状态机和明确的测试入口控制，而不是让“这次刚好没复现”成为常态。
